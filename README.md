# 🪔 Pavitra Pooja - E-Commerce Platform

A production-quality e-commerce platform for authentic Indian spiritual products built with Next.js, Tailwind CSS, TypeScript, and Prisma.

---

## 🛠️ How to Open and Run in VS Code

### 1. Open in VS Code
- Open **VS Code**.
- Click **File** ➔ **Open Folder...**
- Select the folder: `c:\Users\dj130\Downloads\pooja samgri`
- *(Alternatively, open PowerShell/Command Prompt inside the folder and type `code .`)*

### 2. Run the Development Server
Inside VS Code:
1. Press `Ctrl + ~` (or `Ctrl + ` ` `) to open the built-in terminal.
2. Run:
   ```bash
   npm run dev
   ```
3. Open your browser and go to:
   ```
   http://localhost:3000
   ```

### 3. Database Management & Commands
- **View/Seed Database**:
  ```bash
  npm run db:seed
  ```
- **Open Prisma Studio (Database GUI)**:
  ```bash
  npx prisma studio
  ```
  *(Prisma Studio lets you visually edit products, categories, orders, and users directly in your browser)*
